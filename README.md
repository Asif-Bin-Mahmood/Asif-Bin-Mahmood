## About

I am a Computer Science and Engineering student at **BRAC University** building a practical cybersecurity portfolio through labs, CTFs, technical writing, and hands-on security research.

My main interest is the space where offensive security knowledge becomes useful defensive capability: understanding how attacks work, documenting them clearly, and using that knowledge to think like a SOC analyst. I have been developing my foundation through web application pentesting, OWASP Top 10 practice, digital forensics, network analysis, and TryHackMe learning paths.

GitHub is where I turn that learning into visible work: structured notes, polished write-ups, attack-chain documentation, remediation summaries, and research ideas.
